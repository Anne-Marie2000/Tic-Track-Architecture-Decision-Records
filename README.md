for Mobile Application Development.

## About the App

Tic Track lets two players compete on a 3x3 board. The app detects wins and
draws, tracks scores across games, and includes a reset button to start a
new round.

Features:
- Tic Tac Toe board
- Two-player mode
- Winner detection
- Draw detection
- Reset button
- Score tracking
